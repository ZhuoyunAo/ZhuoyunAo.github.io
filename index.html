About GDELT

GDELT is the Global Database of Events, Language and Tone - a comprehensive source of worldwide events data.

Key Features:

  • Search across millions of articles
  • Filter by language, country, and domain
  • Analyze trends over time with timeline visualization
  • Geographic analysis of events
  • TV monitoring data
  • Compare multiple queries

For more information, visit GDELT Project

Compare Data

Use the Compare feature to analyze multiple queries side by side.

  1. Set up a query and click "Add" to save the data
  2. Modify the query and click "Add" again
